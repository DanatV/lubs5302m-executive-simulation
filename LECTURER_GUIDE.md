# Lecturer guide

## Before class
Open index.html on a teaching device and keep an unzipped offline copy. If hosting, test that URL too. Confirm report downloads and printing in the browsers used in the lab. Assign one number to each team; ask teams to use one shared device. No names or logins are needed. Read MODEL_CARD.md and SCENARIOS.md.

## Suggested 60-minute lab
- 0–8 minutes: briefing and relation to student-built decision trees.
- 8–25: inspect parameter settings, compare evidence, discuss confusion matrices and CV.
- 25–32: deliberate and submit the first package.
- 32–42: review interim results and external development; choose one adjustment.
- 42–50: review final results and prepare a board report.
- 50–60: compare strategies and debrief.

Teams move at their own pace. There is no remote instructor gate or hidden authentication. Instruct teams verbally if you want to synchronise the first reveal.

## Dashboard discussion
Number of trees changes the ensemble size; maximum depth changes each tree's allowed complexity. Accuracy is not the same as probability calibration or business value. CV results are comparable because folds are fixed. The holdout panel should be audited after considering CV; repeatedly selecting by test results is itself a useful cautionary discussion.

Permutation importance reflects predictive reliance under this fictional data distribution, not the benefit of a pound of spending. The summary tree intentionally follows QS≤100 → tuition → interactive learning; individual forest roots can differ. Surrogate agreement measures imitation of the ensemble rather than correctness against student choices.

## Strategy and consequences
See SCENARIOS.md for all exact allocations and twelve endings. These outcomes are authored and deterministic. Do not tell teams that the forest caused them. The experience index is a separate fictional business indicator. All teams encounter the same external development. There are competing outcomes rather than an overall winner.

## Debrief questions
- Did a top predictor also offer the greatest controllable marginal return?
- Does crossing a threshold guarantee a recruitment collapse?
- What does greater training accuracy tell you without validation?
- What evidence would distinguish prediction from causation?
- What assumptions connect fees or engagement to a real budget intervention?
- How would you manage delivery capacity when recruitment increases?
- How could changing competitor behaviour affect historical predictions?
- Which stakeholder might reasonably prefer a different package?

Optional student reflections are in the app; no written answer is graded by the software.

## Collecting work
Ask teams to download HTML reports or use Print / Save as PDF and submit through the Minerva or via email to d.valizade@leeds.ac.uk. JSON is a portable session backup; it is not an authenticated assessment receipt. GitHub Pages does not receive submissions. Files can be inspected or edited, so use the activity for learning rather than secure assessment.

## Offline contingency
Distribute the ZIP before class, unzip and open index.html. All assets and model outputs are local. If browser storage is blocked, download session JSON before closing. To move devices or from offline to hosted use, export JSON then import it. No central team synchronisation exists.

## Pre-class manual checks still recommended
Test your lab's Safari/Firefox versions if used, browser PDF dialogue, keyboard focus and a screen reader with the institution's accessibility setup. A responsive automated check is not a substitute for testing on the actual teaching equipment.

## Regional evidence and revised interim outcomes
Use the origin selector to compare four fictional regional model sets (64 configurations total). These differences were specified as teaching assumptions, not estimated from real regional populations. QS dominates in East and South East Asia, with social media third; fees dominate elsewhere. The selected region is recorded in submitted evidence and reports. One optional long reflection uses three guiding questions. Package D now has 2,800 interim enrolments and 35% conversion; its unchanged final intakes are lower. Interim ranking positions are A=99, B=110, C=110, D=105.
